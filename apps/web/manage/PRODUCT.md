# Radar 信源管理

本页面面向维护个人 Radar 的管理员，供 work-os 的「Radar 信源管理」入口直接访问。

- 在同一个页面切换医疗和 AI，默认医疗，行业保存在 URL 中。
- 复用现有信源列表、新增、编辑和删除功能。操作只作用于明确选择的行业。
- 两行业保持独立数据库、管理员会话、CSRF、采集开关和付费预算。
- 认证沿用 Authentik 和管理员密码；登录后回到原来的行业与管理路径。
- 有未保存修改时，切换或离开先确认；请求进行中不能离开当前表单。
- work-os 负责导航，Radar 负责页面和业务权限；不向 work-os 复制业务数据。
- 继承现有后台的纸色、墨色、青色与组件，不重新设计整个站点。

本轮使用本机隔离数据库验收 CRUD，NAS 只读核对已有来源；验收夹具和凭据不提交。
