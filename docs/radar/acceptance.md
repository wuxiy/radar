## 可复验入口

先看 [运行说明](run.md)。测试只能使用新建的 `_test` / `_ci` 空库，禁止使用已有业务库。普通运行关闭全部真实服务；本轮用户另行授权的模型测试只访问本机模拟接口。

```bash
npm run typecheck
# 先迁移全新空的 DATABASE_URL；模型测试需本机模拟及回环网络保护。
node scripts/migrate.ts
npm test
npm run build -w @aihot/web
node --test apps/web/tests/*.test.ts
npm run radar:build
node --conditions=radar-ai scripts/smoke.ts --base http://localhost:3000/ai
node --conditions=medical scripts/smoke.ts --base http://localhost:3000/medical
# 两个运行库都必须为专用 *_test / *_ci；默认清理验收样本。
node --env-file=<私有测试配置> scripts/verify-radar.ts
```

`verify-radar.ts` 是可重跑的运行验收，包含明确标记的同编号样本、公开出口、版权范围、后台会话、路由跳转、读者回执计数、队列和预算隔离；默认清理样本。本轮浏览器和备份验证完成后已清理运行库的样本。模拟内容不是已采集的行业新闻。
